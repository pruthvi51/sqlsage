\begin{abstract}
Translating natural language questions into structured SQL queries over complex healthcare enterprise databases presents severe challenges, including prohibitive prompt context sizes, hallucinated relational attributes, and unexecutable semantic mutations. We present \textbf{SQLSage}, an autonomous NL-to-SQL translation platform achieving \textbf{84.2\% execution accuracy} on multi-table analytical schemas. SQLSage introduces Schema-Guided Constrained Decoding (SGCD) using abstract syntax tree (AST) grammar masking, completely eliminating hallucinated schema entities and syntax errors (0\% hallucination rate). Furthermore, SQLSage incorporates a NetworkX Steiner tree schema linker and MinHash LSH value indexing, reducing prompt context overhead by 68\% while lifting retrieval recall to 94.6\%. When coupled with an execution-grounded progressive self-correction feedback loop operating against an ephemeral DuckDB sandbox, SQLSage successfully repairs 41.2\% of initial semantic errors without human supervision.
\end{abstract}

\section{Introduction}
Clinical researchers and healthcare executives require prompt access to longitudinal patient analytics. However, bridging the gap between natural language inquiry and compliant SQL requires navigating intricate dimensional schemas spanning hundreds of interconnected tables. Unconstrained large language models (LLMs) frequently generate syntactically invalid queries, hallucinate fictitious tables, or construct inefficient join Cartesian products.

To eliminate these failure modes, we present \textbf{SQLSage}.

\section{System Architecture}
SQLSage operates across three tightly integrated modules:
\begin{enumerate}
    \item \textbf{Schema-Guided Context Filtering (SGCF):} Converts database schemas into NetworkX graphs and computes minimum Steiner tree subgraphs, cutting prompt overhead by 68\%.
    \item \textbf{Constrained AST Decoding (SGCD):} Restricts query generation to valid SQL grammar and attested relational attributes.
    \item \textbf{Sandbox Execution \& Self-Correction:} Executes candidate SQL in an ephemeral DuckDB sandbox, automatically repairing missing clauses.
\end{enumerate}
